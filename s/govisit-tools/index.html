Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http govisit-tools https://govisit.ai/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://govisit.ai/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "govisit-tools": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://govisit.ai/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "govisit-tools": {
      "url": "https://govisit.ai/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "govisit-tools": {
      "type": "http",
      "url": "https://govisit.ai/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "govisit-tools", "type": "http", "url": "https://govisit.ai/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "govisit-tools": {
      "serverUrl": "https://govisit.ai/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://govisit.ai/mcp
{
  "mcpServers": {
    "govisit-tools": {
      "type": "http",
      "url": "https://govisit.ai/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

search_placesread-onlyFor faster searches, pass a known country or destination code. Unscoped name lookups search all covered …

For faster searches, pass a known country or destination code. Unscoped name lookups search all covered countries. Search published places by name or traveler intent. mode defaults to auto: exact names avoid embedding, otherwise combine name and intent candidates without duplicate IDs. Explicit name never embeds. A destination page supplies its scope; country, destination and near intersect and never widen. Scoped names and proximity require a geography-enabled index release; older releases report unavailable constraints. At most 200 candidate records are examined before returning up to 20 items, with counts/truncation; a missing result is not proof of invisibility everywhere. Distance is geographic meters, not walking time. Scores and profile quality are retrieval signals, not proof of amenities or suitability. Intent uses one query embedding.

ParameterTypeDescription
querystringrequiredPlace or destination name, or the traveler's intent.
modestringoptionalName lookup, intent retrieval, or name-first auto discovery. One of: auto, name, intent
limitintegeroptionalMaximum number of places to return. Defaults to 10. Name mode allows up to 10. Other modes allow up to 20.
languagestringoptionalRequested response language; defaults to the page language. One of: en, cs
destinationstringoptionalStable destination code or all. Defaults to the current destination, otherwise all.
countrystringoptionalTwo-letter ISO country code. Supply it when the country is known to narrow the search. Intersects destination and proximity where the public geography projection is available.
nearobjectoptionalProximity filter with a radius in meters. Supply either a GoVisit place ID or explicit coordinates as the reference.
