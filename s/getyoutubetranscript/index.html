Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http getyoutubetranscript https://getyoutubetranscript.com/api/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://getyoutubetranscript.com/api/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "getyoutubetranscript": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://getyoutubetranscript.com/api/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "getyoutubetranscript": {
      "url": "https://getyoutubetranscript.com/api/mcp"
    }
  }
}

VS Code

Other clients

Most clients accept this shape. The endpoint is:

{
  "mcpServers": {
    "getyoutubetranscript": {
      "type": "http",

    }

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

get_youtube_transcriptread-onlyexternal accessUse this when the user shares a YouTube video link or ID, or asks to summarize, explain, quote, translate, …

Use this when the user shares a YouTube video link or ID, or asks to summarize, explain, quote, translate, take notes on, or chat about a specific YouTube video, lecture, podcast, or talk. Returns the full spoken text (captions) as one block, plus the title and channel. Set timestamps to true when the user wants timestamps, wants to find or quote where something is said, or wants a timeline or chapter breakdown: each caption line then starts with its [m:ss] time. Accepts watch, youtu.be, Shorts, and live URLs. Do not use for non-YouTube videos or for files the user uploads. If a video has no captions, this returns an error by default: tell the user instead of guessing what the video says. If the user wants a transcript anyway, call again with mode 'auto' (captions if any, otherwise an AI speech-to-text transcript at 3 credits per minute of video). Long videos may answer with a job_id instead of text: then call get_transcript_job.

ParameterTypeDescription
video_urlstringrequiredYouTube URL (full or short) or an 11-character video ID
languagestringoptionalLanguage code, e.g. 'en', 'es'. Defaults to 'en'.
send_metadatabooleanoptionalInclude title/author/thumbnail metadata. Defaults to true.
timestampsbooleanoptionalOne line per caption, each starting with its [m:ss] start time. Defaults to false (one block of text).
translatestringoptionalLanguage code to machine-translate the transcript into, e.g. 'es', 'zh-CN'. Timestamps stay aligned. Use when the user wants the video's text in another language.
modestringoptional'native' (default): captions only, 1 credit. 'auto': captions if the video has any (1 credit), otherwise an AI speech-to-text transcript of the audio. 'generate': always an AI transcript. AI transcripts cost 3 credits per minute of video (rounded up), up to 4 … One of: native, generate, auto

Example call (required arguments only, placeholder values):

{
  "method": "tools/call",
  "params": {
    "name": "get_youtube_transcript",
    "arguments": {
      "video_url": "..."
    }
  }
}
