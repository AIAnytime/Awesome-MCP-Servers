Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http council-of-ai-gspc https://councilof.ai/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://councilof.ai/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "council-of-ai-gspc": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://councilof.ai/mcp"
      ]
    }
  }
}

Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "council-of-ai-gspc": {
      "url": "https://councilof.ai/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

art50_marking_evidencecan modifyexternal accessPAID (x402 or CSOAI LTD invoice). Article 50 marking-evidence pack via …

PAID (x402 or CSOAI LTD invoice). Article 50 marking-evidence pack via https://councilof.ai/api/art50/marking-evidence: which machine-readable marks the named methods DETECT in these bytes right now. Scope: C2PA and IPTC metadata only (C2PA manifest store, assertion hashes, hard binding, claim signature; IPTC digitalSourceType); no watermark, fingerprint or other kind of mark is read. NOT_DETECTED is not unmarked: Article 50(2) is technology-neutral, so a mark this pack cannot read may be present, and metadata is often stripped on re-save. Disclosure: CSOAI is a member of the C2PA, whose specification is one of the two methods read. The pack carries the verbatim Art 50(2) text hash and the dates it turns on. Point-in-time detection — never a conformity opinion, never a compliance word of any kind. preview=true is free and returns the same measurement unsigned. Without x_payment the tool returns the 402 challenge. If the route is not deployed on this origin the tool says NOT_DEPLOYED rather than inventing a result.

ParameterTypeDescription
urlstringoptionalPublic HTTP(S) URL of the generative output to measure (≤20 MiB). The server fetches only this declared measurement subject.
bytes_b64stringoptionalAlternatively the output bytes, base64 (≤20 MiB decoded).
manifest_b64stringoptionalAlternatively a detached C2PA manifest store, base64 (manifest-only mode).
previewbooleanoptionaltrue = free unsigned measurement (no card sha, no signature).
x_paymentstringoptionalThe X-PAYMENT header value signed against accepts[] from the previous 402. Omit to receive the challenge.
purchase_actionstringoptionalSelfserve account-owned purchase action. Use Council bearer transport, omit x_payment; no new financial/provider action. One of: history, recover, decisions, accept, reject, request_correction
purchase_transactionstringoptional
purchase_result_sha256stringoptional
purchase_result_versionstringoptional
purchase_request_idstringoptionalIdempotency id for the same exact decision intent, or exact id lookup when reading decisions. Never change inputs on an unknown write.
purchase_cursorstringoptionalOwner-scoped history/decision page cursor; do not combine with exact decision id.
purchase_reasonstringoptional

Verify a signed gspc.measurement-card under the published rule (https://councilof.ai/signed/HOW-TO-VERIFY.md): recompute the id from the canonical body bytes, then check the Ed25519 signature under a key PINNED in this verifier and published in the did:web:csoai.org DID document: #card-attestation-1 (the card key of the signed card index) or #card-attestation-2 (the card key added on rotation, 27 Sep 2026; a card names the key it was signed under), plus the board key for the cards it signed. pinned_key in the result names the key that matched. A card that carries its own key proves only that the file is self-consistent — anyone can alter a body and sign it with a key they just generated — so an inline key outside the pinned set is reported INVALID, and a DID key reference outside it UNCHECKABLE.
