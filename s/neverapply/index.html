Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http neverapply https://neverapply.co/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://neverapply.co/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "neverapply": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://neverapply.co/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "neverapply": {
      "url": "https://neverapply.co/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "neverapply": {
      "type": "http",
      "url": "https://neverapply.co/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "neverapply", "type": "http", "url": "https://neverapply.co/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "neverapply": {
      "serverUrl": "https://neverapply.co/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://neverapply.co/mcp
{
  "mcpServers": {
    "neverapply": {
      "type": "http",

    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

answer_screening_questioncan modifydestructiveexternal accessSave only the facts-vault choice IDs currently offered by get_application, with its review_version. Supply …

Save only the facts-vault choice IDs currently offered by get_application, with its review_version. Supply all outstanding questions together. Never accepts free-text answers. Answering can submit the application: when the choices answer the last open question of a job paused for answers, NeverApply resumes it and submits it to the employer under the permission given when it started (the member's approval of that job or this assistant's standing send grant). Before the call that answers the last question, tell the member that it will submit the application to the employer, and get their agreement. If a question has no offered choice, ask the member to update the relevant fact or use the hosted application page; file uploads require that page. Sending a held run requires separate fresh approval through approve_application.

Decide one of the authenticated user's historical application reviews.
