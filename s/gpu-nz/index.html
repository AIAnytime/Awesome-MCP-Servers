gpu.nz GPU Cloud

Find GPU servers with live per-minute prices, estimate how much VRAM an LLM or image model needs, and launch, monitor and stop GPU servers (ComfyUI, Ollama, vLLM, Jupyter) on the gpu.nz cloud. Browsing and VRAM estimates need no key; renting needs an API key. Endpoint: https://gpu.nz/mcp · Docs

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http gpu-nz https://gpu.nz/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://gpu.nz/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "gpu-nz": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://gpu.nz/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "gpu-nz": {
      "url": "https://gpu.nz/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "gpu-nz": {
      "type": "http",
      "url": "https://gpu.nz/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "gpu-nz", "type": "http", "url": "https://gpu.nz/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "gpu-nz": {
      "serverUrl": "https://gpu.nz/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://gpu.nz/mcp
{
  "mcpServers": {
    "gpu-nz": {
      "type": "http",
      "url": "https://gpu.nz/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.
