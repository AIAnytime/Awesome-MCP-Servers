Questions

What is an MCP server?

An MCP server exposes tools, data or prompts to an AI assistant through the Model Context Protocol, an open standard. A client such as Claude, Cursor or VS Code connects to the server and can then call its tools.

How is this directory different from other MCP server lists?

Every hosted server here is sent a real MCP handshake each night. The directory shows which servers answered, which asked for credentials, how many tools each one exposes and roughly how many tokens those tool definitions take up in a model's context.

What do Live, Needs auth and Down mean?

Live means the server answered an MCP initialize request without any credentials. Needs auth means it is reachable but asked for an OAuth sign-in or an API key first. Down means it did not return a valid MCP response. Local stdio servers run on your own machine and are not checked.

What is context cost?

A client loads every tool definition a server exposes into the model's context. Context cost is an estimate of how many tokens those definitions take, at about four characters per token. A server with hundreds of tools can use tens of thousands of tokens before you ask anything.

Does a listing mean a server is safe?

No. The nightly check records what a server answered, not whether it is safe. A listing is not a security audit. Read a server's source and the permissions it asks for before you connect it.

How do I add my MCP server?

Open a pull request on GitHub that adds one small JSON file for your server. Once it merges, the server gets its own page, a nightly check and a status badge you can embed in your README.

Can an AI agent search this directory?

Yes. The whole directory is available as a JSON file and as llms.txt and llms-full.txt, and the repository includes an MCP server that searches the directory by keyword, category and live status.
