Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http vedar https://vedarai.ru/api/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://vedarai.ru/api/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "vedar": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://vedarai.ru/api/mcp"
      ]
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Cancel or move a Kamchatka tour request by its status key when the person asks; the call returns a Vedar link, the person confirms there. Key from create_booking_request; call only when the person asked. The call changes nothing: give the person confirm_url; only their click on the Vedar page changes the request.
