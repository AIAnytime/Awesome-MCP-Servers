Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http no-stairs-please https://nostairsplease.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://nostairsplease.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "no-stairs-please": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://nostairsplease.com/mcp"
      ]
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

find_by_performerread-onlyLook up a band or solo performer across all 50 US states, Washington, DC, and British Columbia. With All …

Look up a band or solo performer across all 50 US states, Washington, DC, and British Columbia. With All Access, returns the artist dossier (genres, live draw / room-cap estimate, bio, typical headlining ticket price, booking/management contacts, website/socials, and top co-billed peers) plus every venue with past or upcoming show listings, dates, and source URLs. With a signed-in free account, returns aggregate show and venue counts across states. Anonymous callers are prompted to sign in.

include_possiblebooleanoptionalInclude fuzzy / possible lineup matches (default false).
statestringoptionalOptional two-letter state/jurisdiction code (all 50 US states, "DC", "BC") or full name.
limitnumberoptionalMaximum venues to return (1-50, default 20).

Example call (required arguments only, placeholder values):

{
