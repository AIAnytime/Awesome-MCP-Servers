Grey Ridge x402 Market & DeFi Data

Keyless market data for Base agents: live DeFi yields, perp funding rates, crypto spot prices and prediction-market odds, plus a pre-trade token-safety gate (GO/HOLD/BLOCK swap verdicts; honeypot, transfer-tax and liquidity checks). Free preview tools; paid calls settle per request in USDC via x402, no key or account. Endpoint: https://x402-data-api.sigrunner.workers.dev/mcp

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http grey-ridge-x402 https://x402-data-api.sigrunner.workers.dev/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://x402-data-api.sigrunner.workers.dev/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "grey-ridge-x402": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://x402-data-api.sigrunner.workers.dev/mcp"
      ]
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.
