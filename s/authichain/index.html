Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http authichain https://authichain.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://authichain.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "authichain": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://authichain.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "authichain": {
      "url": "https://authichain.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "authichain": {
      "type": "http",
      "url": "https://authichain.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "authichain", "type": "http", "url": "https://authichain.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "authichain": {
      "serverUrl": "https://authichain.com/mcp"
    }
  }
}

    }

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Free informational EU Digital Product Passport readiness questionnaire; this cannot issue a passport or certify compliance. x402 paid seal-registry verification; use only after separate payment authorization, not for free lookup. Arguments that cannot be a seal UUID are HTTP 400 before payment.
