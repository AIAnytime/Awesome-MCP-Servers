Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http hey-research-lab https://heyresearch.xyz/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://heyresearch.xyz/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "hey-research-lab": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://heyresearch.xyz/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "hey-research-lab": {
      "url": "https://heyresearch.xyz/mcp"
    }
  }
}

VS Code

Or add it to .vscode/mcp.json:

{

    "hey-research-lab": {

Or from a terminal:

code --add-mcp '{"name": "hey-research-lab", "type": "http", "url": "https://heyresearch.xyz/mcp"}'

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Which Robinhood Chain project is this name, $TICKER or 0x contract, and is anyone building it? A full 0x address is a contract lookup: its ships in 30 days, the last one with its source. Surfaces: building-with-token: shipping, active or resumed, with a token whose market is live. still-building: counted ships during a market drawdown HEY itself tracked. under-the-radar: eligible under HEY's Under the Radar rule (status shipping, active or resumed; Build Momentum at least 30; at least 2 counted ships in the last 30 days, one of them a ship rather than a commit summary; a fresh reading of an active market beyond a launch curve or a launch pool, trading $1,000+ a day, for the project's own token; market attention TYPICAL or lower (percentile below 60); never on activity HEY cannot read or a ticker another project's token carries, on a token the project has not named) and a positive Discovery Gap — market-attention percentile below the build percentile; a positive gap alone is not enough. shipping-now: status SHIPPING. most-active: shipping, active or resumed, by Build Momentum. new-builders: new in 7 days, with a builder source and a counted ship; new-on-hey: any page new in 7 days. back-from-dormancy: status RESUMED, narrowed to Verified Builders native to the chain (status=RESUMED gives all of them). utility, memes: by kind. shipping-in-silence: held Under the Radar AND …
