Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http shortform-kit https://shortformkit.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://shortformkit.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "shortform-kit": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://shortformkit.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "shortform-kit": {
      "url": "https://shortformkit.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "shortform-kit": {
      "type": "http",
      "url": "https://shortformkit.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "shortform-kit", "type": "http", "url": "https://shortformkit.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "shortform-kit": {
      "serverUrl": "https://shortformkit.com/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

creator_monetizationread-onlyLook up sourced 2026 creator-income data. topic=programs lists monetization programs with eligibility …

Look up sourced 2026 creator-income data. topic=programs lists monetization programs with eligibility (subscribers, watch hours, views) and status; rpm_by_niche and rpm_by_country give earnings per 1,000 views as low, high and median; engagement_benchmarks gives typical engagement rates; sponsorship_rates gives price ranges per post. Every row carries its sources. Use it to answer 'how much does X pay' or 'what do I need to monetize'; for a concrete earnings estimate from a view count use estimate_youtube_earnings instead. Offline data, max 40 rows.

ParameterTypeDescription
topicstringoptionalWhich table to read. One of: programs, rpm_by_niche, rpm_by_country, engagement_benchmarks, sponsorship_rates
platformstringoptionalOptional platform filter, substring: YouTube, TikTok, Instagram, Facebook, X, Snapchat ...
nichestringoptionalOptional niche filter for rpm_by_niche and sponsorship_rates, substring: finance, tech, gaming, beauty, education ...
countrystringoptionalOptional country filter for rpm_by_country: ISO code (US, DE, IN) or English name.

Example call (required arguments only, placeholder values):

{
  "method": "tools/call",
  "params": {
    "name": "creator_monetization",
    "arguments": {}
  }
}
download_mediacan modifyexternal accessCreate a temporary download of a public post. Returns a job object with status and, when done, download_url …

Create a temporary download of a public post. Returns a job object with status and, when done, download_url (valid 15 minutes) plus job_status_url to poll if it is still running after about 100 seconds. Use kind=video for MP4, audio for MP3, image for photo posts and carousels, thumbnail for the cover, frame for a still at one timestamp. For the spoken text use transcribe_video instead. Videos up to 12 hours. Only for content the user made, has permission to use, or that is freely licensed. Music is refused: songs, music videos, YouTube Music and copyrighted sounds return an error, do not try to work around it.

ParameterTypeDescription
urlstringrequiredLink to a public post or video, e.g. https://www.instagram.com/reel/..., https://www.tiktok.com/@user/video/..., https://youtu.be/... Private posts and login-only content fail.
kindstringoptionalWhat to save: video (MP4), audio (MP3), image (photo/carousel), thumbnail (cover image) or frame (one still, needs 'at'). One of: video, audio, image, thumbnail, frame
qualityintegeroptionalMaximum video height in pixels, e.g. 720, 1080, 2160. Omit for the best available. Only for kind=video.
startstringoptionalOptional start of a section to cut. Time as '1:05', '0:01:05' or seconds ('65').
endstringoptionalOptional end of the section, must be after start. Time as '1:05', '0:01:05' or seconds ('65').
atstringoptionalTimestamp of the still for kind=frame. Time as '1:05', '0:01:05' or seconds ('65').

Example call (required arguments only, placeholder values):

{
  "method": "tools/call",
  "params": {
    "name": "download_media",
    "arguments": {
      "url": "..."
    }
  }
}
estimate_youtube_earningsread-onlyEstimate YouTube ad revenue for a channel from its monthly views. Returns the RPM range in USD, monthly and …

Estimate YouTube ad revenue for a channel from its monthly views. Returns the RPM range in USD, monthly and yearly USD ranges, the model used and a link to the interactive calculator. Ads only, no sponsorships or memberships. Use creator_monetization for the underlying RPM tables and program requirements.

ParameterTypeDescription

nichestringoptionalContent niche, drives the ad rate. Ignored when shorts=true. One of: beauty, education, finance, gaming, health, music, tech, travel …
shortsbooleanoptionaltrue = views are YouTube Shorts views (pooled Shorts revenue, much lower RPM).

Example call (required arguments only, placeholder values):

Read the metadata of a public Instagram, YouTube, TikTok, X, Facebook or Pinterest post without downloading it. transcribe_videocan modifyexternal accessTranscribe the speech of a public video, Reel, TikTok or Short with Whisper on the server. Returns the plain …

Transcribe the speech of a public video, Reel, TikTok or Short with Whisper on the server.
