Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http agent-flights https://lowest.flights/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://lowest.flights/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "agent-flights": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://lowest.flights/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "agent-flights": {
      "url": "https://lowest.flights/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "agent-flights": {
      "type": "http",
      "url": "https://lowest.flights/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "agent-flights", "type": "http", "url": "https://lowest.flights/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{

    "agent-flights": {

  }
}

Most clients accept this shape. The endpoint is:

{
  "mcpServers": {
    "agent-flights": {
      "type": "http",
      "url": "https://lowest.flights/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

search_flightsread-onlyexternal accessSearch cheap flights between two airports or cities and return the cheapest all-in fare plus a …

Search cheap flights between two airports or cities and return the cheapest all-in fare plus a cheapest-sensible alternative (penalises 20h+ layovers and risky overnight transfers). Compares live fares and cached data where available, expands nearby airports and combines self-transfer one-ways when cheaper. One-way, return, multi-passenger, cabin and bag filters. Example: {"origin":"ABJ","destination":"CDG","departureDate":"2026-12-18","returnDate":"2027-01-05","flexDays":3,"currency":"XOF"}. Returns {cheapest, cheapestSensible, offers[] (each with bookingLink and bookingOptions on several booking sites), sources, notes}. Compact by default; view=full for every field.

ParameterTypeDescription
originstringrequiredDeparture airport or city: a 3-letter IATA airport/metro code (ABJ, DSS, LOS, CDG, LON, NYC) or a plain name ("Abidjan", "Paris").
destinationstringrequiredArrival airport or city: a 3-letter IATA airport/metro code (ABJ, DSS, LOS, CDG, LON, NYC) or a plain name ("Abidjan", "Paris").
departureDatestringrequiredOutbound date, YYYY-MM-DD.
returnDatestringoptionalReturn date YYYY-MM-DD. Omit for one-way.
flexDaysintegeroptionalAlso search ± this many days around the dates. 3 finds the cheapest fare that exists.
nearbyAirportsbooleanoptionalInclude metro and alternate airports (LON, PAR, NYC, DKR/DSS, LOS/ABV, ACC/KMS). Default true.
stitchSelfTransferbooleanoptionalCombine one-way tickets through hubs (CMN, LFW, LIS, IST…) when cheaper. Default true.
adultsintegeroptionalAdults (12+). Default 1.
childrenintegeroptionalChildren (2–11). Default 0.
infantsintegeroptionalInfants on lap (<2). Default 0.
currencystringoptionalISO 4217 display currency. Default EUR. XOF is shown as FCFA.
cabinClassstringoptionalCabin. Default economy. One of: economy, premium_economy, business, first
checkedBagsPerAdultintegeroptionalChecked bags per adult to price in. Default 0.
allowSelfTransferbooleanoptionalAllow self-transfer itineraries. Default true.
maxStopsintegeroptionalMaximum stops per direction. 0 = direct only.
limitintegeroptionalMax offers returned. Default 10 in compact view, 20 in full view.
viewstringoptionalcompact (default): about 500 bytes per offer (price in your currency, times, stops, carriers, flight numbers, warnings, one tracked bookingLink). full: every field incl. per-site bookingOptions and segment airport names. One of: compact, full
