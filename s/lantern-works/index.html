Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http lantern-works https://lantern-works-mcp.lantern-works.workers.dev/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://lantern-works-mcp.lantern-works.workers.dev/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "lantern-works": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://lantern-works-mcp.lantern-works.workers.dev/mcp"
      ]
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Cost of one GPU job (not cost per hour) among tracked providers, cheapest current compute subtotal first. gpu_family (e.g. 'H100', 'A100 80GB') or its alias gpu (same name compare_gpu_prices uses) is required; if both are given they must match, else invalid_argument. gpus_per_job defaults to 1. You supply the duration: job_hours, OR work_units plus throughput_units_per_gpu_hour from your own benchmark (job_hours = work_units / (throughput x gpus_per_job)). Otherwise not_found 'missing: throughput for {gpu}'. Whole-instance billing: instances = ceil(gpus_per_job / gpus_per_instance), all allocated GPUs billed (9 GPUs on an 8-GPU-only offer bill 16). optimize_agent_stackread-onlyexternal accessEstimate a monthly stack cost from a short description of the agent being built. description: free text, e.g. …

Estimate a monthly stack cost from a short description of the agent being built. description: free text, e.g. 'scrapes 20k JS pages/month via 5 GB residential proxies, 3k search queries, summarizes with an LLM, budget $300/mo'. Parsed deterministically (keywords/regex, no LLM) into components: gpu, scraping, proxy, search, llm_api, email, hosting, database, monitoring. Optional fields override the parse: gpu_hours (GPU-hours/month), gpu_model ('H100', 'A100', 'RTX 4090'), model_size_b (billions of params; sets a minimum VRAM using FP16 x 1.2), scrape_pages, js_rendering, proxy_gb, search_queries, emails_sent, llm_api, monthly_budget_usd. Each component gets the cheapest option with a cited price among tracked providers, with calc, source_url, verified_at, referral_disclosure (set when the link is a referral link) and manual-signup notes. Components with no cited price say 'no sourced price tracked' (nothing is estimated). Totals show the math and say whether they are complete. Pulled listings are excluded. Every option has data_age_hours, degraded (> 48 h) and stale (> 7 days); GPU prices older than 168 h never rank by default (listed in the line's stale_prices); max_data_age_hours replaces that default and drops older options (excluded_too_old counts them). Same data as optimize_stack, compare_gpu_prices and the deal feed.
