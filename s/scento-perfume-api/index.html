Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http scento-perfume-api https://www.scento.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://www.scento.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "scento-perfume-api": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.scento.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "scento-perfume-api": {
      "url": "https://www.scento.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "scento-perfume-api": {
      "type": "http",
      "url": "https://www.scento.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "scento-perfume-api", "type": "http", "url": "https://www.scento.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "scento-perfume-api": {
      "serverUrl": "https://www.scento.com/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://www.scento.com/mcp
{
  "mcpServers": {
    "scento-perfume-api": {
      "type": "http",
      "url": "https://www.scento.com/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

family-mapread-onlyUse this when the user asks how fragrances are grouped or what a scent family is (for example woody, floral, …

Use this when the user asks how fragrances are grouped or what a scent family is (for example woody, floral, amber, fresh, citrus), or wants the exemplar perfumes of one family (synonyms: scent families, fragrance categories, olfactive families). Returns Scento's own family system: the whole tree, or one family with its definition, subfamilies, exemplar perfumes and neighbouring families, with the scento.com guide. Don't use for one perfume's family (perfume-portrait), a perfumery term (perfumery-lexicon) or an occasion (occasion-edit).

langstringoptionalLanguage of the scento.com links and labels; answers stay in English. Use the language the user writes in, for example "de" (German), "fr" (French), "es" (Spanish) or "it" (Italian). Default "en". One of: en, de, fr, es, it, ro, el, hu …

Use this when the user asks about a perfume house, brand or maison (for example Creed, Le Labo, Amouage): where it is from, when it was founded, its style and its signature perfumes.
