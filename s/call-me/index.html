Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http call-me https://callmemcp.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://callmemcp.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "call-me": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://callmemcp.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "call-me": {
      "url": "https://callmemcp.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "call-me": {
      "type": "http",
      "url": "https://callmemcp.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "call-me", "type": "http", "url": "https://callmemcp.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "call-me": {
      "serverUrl": "https://callmemcp.com/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

callcan modifydestructiveexternal accessRing the human's iPhone, read `question` aloud word for word, and return what they say back. It does not have …

Ring the human's iPhone, read `question` aloud word for word, and return what they say back. It does not have to be a question: an update or a summary of the day ahead works too, up to 2000 characters (about two minutes of speech). Waits up to ~30s; if the result comes back status "ringing" or "in_call", follow up with poll_result. On a local client, read `to` from `~/.aiphone/config.json` → `user_number`; this hosted server cannot read that file itself. It is a Call Me app number, not a regular phone number. If missing, returns setup_required with the App Store link. Pass a previous session_token to stay in the same thread on their phone. By default the call is a conversation: after their answer the line stays up for `say` until you `hang_up`; keep_open=false hangs up after one answer. `language` ("tr", "de", ...) is the language you are speaking; the call's own short lines follow it. Default English.

saycan modifydestructiveexternal accessIn a call placed with keep_open=true, speak `text` to the human and return what they answer, in the same …

In a call placed with keep_open=true, speak `text` to the human and return what they answer, in the same shape as `call`. Only after their previous answer is in. Waits up to ~30s; on "in_call", follow up with poll_result. "open": false means the call has ended. Pass `language` only to switch the language of the call's own lines; empty keeps it. Anything they said while you were thinking comes back as "said_while_waiting".
