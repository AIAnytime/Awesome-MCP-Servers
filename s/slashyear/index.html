Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http slashyear https://slashyear.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://slashyear.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "slashyear": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://slashyear.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "slashyear": {
      "url": "https://slashyear.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "slashyear": {
      "type": "http",
      "url": "https://slashyear.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "slashyear", "type": "http", "url": "https://slashyear.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "slashyear": {
      "serverUrl": "https://slashyear.com/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://slashyear.com/mcp
{
  "mcpServers": {
    "slashyear": {
      "type": "http",
      "url": "https://slashyear.com/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Check one dated sentence against the record before stating it. Leaders, Billboard No. 1 singles and Nobel Prizes get a structured check that can return 'supported' or 'contradicted' with the source. search_historyFull-text search across every dated entry in the historical record, plus the subjects that match. Each entry …

Full-text search across every dated entry in the historical record, plus the subjects that match. Each entry is a sentence quoted verbatim from a numbered English Wikipedia revision and carries that revision id, so an answer built on it can cite a source that will still say the same thing next year.
