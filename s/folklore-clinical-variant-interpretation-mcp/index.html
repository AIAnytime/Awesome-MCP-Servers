Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http folklore-clinical-variant-interpretation-mcp https://api.helena.bio/folklore/v1/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://api.helena.bio/folklore/v1/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "folklore-clinical-variant-interpretation-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://api.helena.bio/folklore/v1/mcp"
      ]
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

classify_germline_variantread-onlyClassify one GRCh38 germline nuclear SNV or simple indel smaller than 50 bp under ACMG/AMP. Accepts genomic, …

Classify one GRCh38 germline nuclear SNV or simple indel smaller than 50 bp under ACMG/AMP. Accepts genomic, coding or protein HGVS, coordinates, SPDI, rsID or a returned canonical key. Returns normalized identity, automated classification, applied criteria, ClinVar assertions, population frequencies, annotations and source provenance when available. Ambiguous input returns candidates for selection.

ParameterTypeDescription
assemblystringoptionalReference genome assembly. Folklore currently accepts GRCh38 only.
querystringrequiredOne germline nuclear SNV or simple indel to resolve and interpret; accepted forms include coordinates, genomic/coding/protein HGVS, SPDI, rsID, or a returned Folklore canonical_key in GRCh38:chrN:position:REF:ALT form.

get_publication_detailsread-onlyRetrieve one publication from Folklore's PubMed-derived genetics corpus, including title, abstract, authors, …

Retrieve one publication from Folklore's PubMed-derived genetics corpus, including title, abstract, authors, journal, publication types, MeSH terms, gene and variant mentions, retraction status and PubMed/PMC links. Pass exactly {"pmid":"12345678"}, using a PMID returned by search_variant_literature or search_literature_corpus. The pmid must be a string of 1 to 12 ASCII digits, not a number, URL, DOI or PMID-prefixed label. This is a corpus lookup, not a lookup of every PubMed record. On publication_not_found, do not retry the same PMID; search_literature_corpus can find available records.

ParameterTypeDescription
pmidstringrequiredOne PMID returned by Folklore literature search, as a JSON string of 1 to 12 ASCII digits. Do not send a number, PMID prefix, URL or DOI. The current corpus does not contain every PubMed record.

Example call (required arguments only, placeholder values):

{
  "method": "tools/call",
  "params": {
    "name": "get_publication_details",
    "arguments": {
      "pmid": "..."
    }

}
