Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http toolbox-pod https://mcp.toolboxpod.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://mcp.toolboxpod.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "toolbox-pod": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.toolboxpod.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "toolbox-pod": {
      "url": "https://mcp.toolboxpod.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "toolbox-pod": {
      "type": "http",
      "url": "https://mcp.toolboxpod.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "toolbox-pod", "type": "http", "url": "https://mcp.toolboxpod.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "toolbox-pod": {
      "serverUrl": "https://mcp.toolboxpod.com/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

{
  "mcpServers": {
    "toolbox-pod": {
      "type": "http",
      "url": "https://mcp.toolboxpod.com/mcp"
    }

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

purchase_ordercan modifydestructiveexternal accessPay for an order with the account's card: real money. BEFORE calling it, tell the person the total (shipping …

Pay for an order with the account's card: real money. BEFORE calling it, tell the person the total (shipping included) and ask them to confirm; call it only after they say yes, unless they clearly asked to pay right now ("buy it now", "go ahead and pay"). "Order", "make an order" or "order these" alone is NOT that: create the order, show the total, and ask. Pass the quoteId and totalCents of the order's offer (create_order, update_order or get_order).
