Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http sfxmint https://sfxmint.com/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://sfxmint.com/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "sfxmint": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://sfxmint.com/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "sfxmint": {
      "url": "https://sfxmint.com/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "sfxmint": {
      "type": "http",
      "url": "https://sfxmint.com/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "sfxmint", "type": "http", "url": "https://sfxmint.com/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "sfxmint": {
      "serverUrl": "https://sfxmint.com/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

get_role_soundread-onlyChoose this when the task calls for a sound for a named event or interaction — a button click, purchase …

Choose this when the task calls for a sound for a named event or interaction — a button click, purchase success, error beep, level-up, dialogue blip, notification. Pass the role as plain words: role ids (click, success, purchase-success, dialogue-blip, notification…) and common aliases (button click, ka-ching, jump scare, text blip…) are all accepted. Returns a qualified candidate for that role when one satisfies the requested constraints, with MP3 and WAV URLs, 2-3 alternates and the family page for browsing more. Free use is MP3: downloading a WAV takes a download pack, and wav_url without one answers 402 wav_needs_pack with the mp3_url to use. Download selected files locally and retain originals. Task-permitted processing requires a recipe, output SHA256, renewed file checks and a listening check. Other task-permitted sources or local synthesis may be mixed in. Optional style: crisp (short, bright, dry), soft (darker, gentler), spacious (reverb, longer tail), balanced (default: most typical). For multiple events consider get_sound_set; use search_sounds for a description or a gap. These are task branches, not a fixed sequence. Unknown roles return not_found with the full role list; GET https://sfxmint.com/api/v1/roles lists roles with aliases.

ParameterTypeDescription

stylestringoptionalOptional. balanced (default) = the family's most typical take; crisp = short, bright, dry; soft = darker, gentler; spacious = reverb, longer tail One of: balanced, crisp, soft, spacious
max_duration_msnumberoptionalHard maximum length of the sound in milliseconds: a file may run longer with near-silence after the sound (audible_ms is the sound, duration_ms the file; checks say which was met).

formatstringoptionalDelivery format the candidate must have (ogg = Ogg Vorbis, only sounds published before 2026-10-14 have it); default MP3 and WAV URLs. Downloading a WAV takes a download pack. One of: wav, mp3, ogg

get_sound_setread-onlyGet a coherent set of sounds for an app or game in one call — one sound per role, with format metadata, …

Get a coherent set of sounds for an app or game in one call — one sound per role, with format metadata, hashes and stable download URLs. Use it when the task needs a whole kit; use get_role_sound for one event. Listen to the files in context. Sets include UI styles, game and app scenarios (fantasy-rpg covers spells, combat, loot, quests and level-up), acoustic-drum-kit, animal-calls (15 isolated calls), and dungeon-traps (6 isolated mechanisms).

search_soundsread-onlyFree-text search over the SFXMint library of free CC0 sound effects. Use it for sound descriptions, …

Free-text search over the SFXMint library of free CC0 sound effects. Use it for sound descriptions, additional constraints or gaps left by another tool. Choose get_role_sound for a named event or get_sound_set for multiple events when that fits the task; these are task branches, not a fixed sequence. Hard constraints (duration, loop, format, excluded words) always apply. results hold sounds whose text has every word of the query. When there are none, closest lists the nearest sounds that meet every hard constraint, best first, each with missing_terms: judge them from title and description and let the user listen. library_fit says how well the library covers the request (full, close, weak, none). Returns direct, hotlinkable MP3 and WAV URLs and verified OGG (Vorbis) URLs where available, no attribution required, plus acoustics measured from the WAV (onset_ms, peak_ms, audible_ms, attack_ms, tail_ms, centroid_hz, peak_dbfs, rms_dbfs), character labels like 'bright · punchy · tight', loop/file-QC status, and score/match as ranking evidence only (role = known role default, exact = all words hit, partial = some words hit, semantic = nearest by meaning). Free use is MP3: downloading a WAV takes a download pack, and wav_url without one answers 402 wav_needs_pack with the mp3_url to use. A measured one-shot with silence before or after it also has trimmed_mp3_url and trimmed_wav_url: the same sound without that silence, counted as the same sound.

formatstringoptionalDelivery format (ogg = Ogg Vorbis, only sounds published before 2026-10-14 have it); loop=true defaults to WAV when omitted. Downloading a WAV takes a download pack. One of: wav, mp3, ogg
