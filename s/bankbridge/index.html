Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http bankbridge https://bankbridge.money/api/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://bankbridge.money/api/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "bankbridge": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://bankbridge.money/api/mcp"
      ]
    }
  }
}

Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{

    "bankbridge": {
      "url": "https://bankbridge.money/api/mcp"
    }
  }
}

VS Code

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Get a link for connecting a new bank account to BankBridge, plus reconnect links for any already-connected bank that needs re-authorization or whose consent expires within 30 days. list_transactionsread-onlyexternal accessList transactions across connected accounts, newest first, with optional filters for date range, account, …

List transactions across connected accounts, newest first, with optional filters for date range, account, category, amount, and pending status. Positive amounts are money spent; negative amounts are money received. Default window is the last 30 days; banks provide up to 24 months. Paginated with limit/offset (default 50, max 100); the response includes total_count and has_more. Each call reads the bank live and banks allow about 30 reads a minute, so totals by category, merchant or month come from get_spending_summary or get_monthly_cashflow in one call rather than from paging through every transaction; when paging is needed, limit=100 keeps the number of calls down. The response includes a `warnings` array of notices about banks that could not contribute (for example, a bank that needs reconnecting), each with a message and, when relevant, a reconnect_url.

Prompts 19

  • balances Quick balance snapshot. Every account, a rolling total, and credit utilization at a glance.
  • weekly-review Last 7 days at a glance. Total spend, biggest charges, and anything new or unusual.
  • spending-by Flexible group-by. Slice your spend by category, merchant, month, or week, for any window.
  • compare-months Side-by-side month comparison with category deltas and callouts for meaningful changes.
  • category-deep-dive Zoom into one category. Every transaction, top merchants, cadence, and the biggest outliers.
  • monthly-check One-page monthly report. Cashflow, top categories, top merchants, subscriptions, investment delta.
  • cashflow-trend Multi-month income vs expenses table + takeaways on where things are trending.
  • budget-draft Draft a realistic monthly budget from your actual last-3-months spending, split into fixed vs variable.
  • portfolio-health Total value, gain/loss, and concentration check. Flags any single position >20% of portfolio.
  • dividends YTD dividends received by ticker, with run-rate and recent payments.
  • monthly-chart Plot a bar chart of income vs expenses for the last N months. Writes cashflow.png.
  • category-pie Pie chart of spending by category (or ASCII donut fallback). Writes spending-pie.png.
  • tax-prep Exports a full year of transactions + category totals to CSV for bookkeeping or tax filing.
  • subscriptions Every recurring charge, sorted, with age and price-drift flags. Surfaces forgettable ones under $20/mo.
  • price-creep Subscriptions whose price increased over the last 12 months. Catch Netflix hikes before your card does.
  • duplicate-check Finds same-merchant + same-amount charges within 48 hours plus statistical outliers.
  • fraud-check Wider net than duplicate-check: unfamiliar merchants, amount outliers, off-hours charges.
  • monthly-report Polished prose report for a given month. Shareable, archivable, email-worthy.
  • year-in-review Spotify Wrapped for your money. Full-year cashflow, top merchants, recurring tax, fun stats.
